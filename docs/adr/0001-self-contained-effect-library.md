# 效果库自包含，不依赖原 mod 启用

选中的效果定义（修饰器 SQL/XML 与 lua）复制进新 mod 自身，运行时不要求同时启用海克斯、通宝、上古之遗等来源 mod。

来源 mod 有十余个且互相依赖（例如 ZPCL 的遗珍表直接操作上古之遗主 mod 的 `SSSC_Relic` 表，无法独立运行）。若做成前置依赖 mod，玩家想用本 mod 就得同时开启并正确排序一大堆 mod，只要缺一个就静默失效——调试成本和玩家门槛都不可接受。

代价：需要把效果定义按条搬进来并解决命名冲突（各 mod 修饰器 ID 前缀不同，冲突风险低但需统一加前缀），且来源 mod 更新后不会自动同步。
